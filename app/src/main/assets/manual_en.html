Equiv Ratio Solver Plus Manual

This app helps you calculate direct or inverse proportionalities from a pair of values, view their graphs and properties, add notes, and perform further calculations using a calculated value.

Data screen

Choose direct or inverse proportionality, then enter any three known, non-zero values in the y₁, x₁, y₂, and x₂ fields. Leave the unknown field empty and press [Done] on the keyboard to calculate it. Use the delete button beside a field to clear that value. The [Store] and [Restore] controls let you save a named proportionality and load it later; [Del] clears the current values.

Use the bottom navigation bar to move between the four screens. The help text on this screen can be hidden with its switch.

Graph screen

After entering a proportionality, open Graph to view its function. Direct proportionality is drawn as a straight line; inverse proportionality is drawn as a hyperbola. The graph shows relevant properties, including the slope and inclination angle for direct proportionality. Use Settings in the menu to choose the displayed decimal places and angle format. Use the [Save Graph] button to save the graph to the Pictures/EquivRatioSolverPlus/ directory.

Result screen

View the calculated values and proportionality properties here. Add notes for the y-values or x-values in the note fields. Use [Send] to share the result or [Save] to store it in [Documents/EquivRatioSolverPlus/ directory.

Operation screen

Select one of the calculated variables and an operation (+, −, multiplication, or division). Enter a number to apply the operation to the selected variable, then enter an optional note. The result and note are shown together below. Use [Send] to share the calculation or [Save] to store it in [Documents/EquivRatioSolverPlus/ directory.

Menu

The menu provides this manual, the proportionality theory guide, settings for language and graph formatting, privacy and license information, donation details, and the option to close the app.
